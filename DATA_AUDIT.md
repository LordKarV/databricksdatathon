# Data and licence audit

Generated by `tools/data_audit.py` from the 2,380 tracked files. Do not edit by hand; rerun the script. Option B (code-only public copy) leaves out every file not in the `public` class; the list is `tools/public_exclude.txt`.

## The two options (the lead and the human owner decide; nothing here changes repo visibility)

- **A. Keep this repo private and invite judges as read-only collaborators.** Everything stays, including the derived tables and hand-check samples that make every number reproducible. Needs: judges' GitHub handles (#3), and confirmation that sharing provided-dataset rows with judges is within the Marketplace consumer terms (judges are participants in the same event).
- **B. Publish a clean code-only copy.** `tools/public_copy.sh` builds it into `build/public/` (git-ignored, local only): every tracked file except those in `tools/public_exclude.txt`, as one fresh commit with no history (this repo's history still holds the excluded files). The copy has no `derived/`, so its notebook and app need `derived/v1` rebuilt from the Marketplace table on Databricks first. That step does not exist yet: `make derived` reads `data/raw/` with paths on the lead's machine. **Waiting for lead:** the Databricks-side pipeline comes with #11 / #57. Numbers quoted from hand checks stay in the docs; their samples do not.

Facility names, phones and claim sentences are found with a dictionary built from derived/v1 (every distinctive facility name, every listed phone, every 8-word span of a claim sentence), not by id format. `public_copy.sh` rescans the built copy with `data_audit.py --check` and fails on any hit. Not covered: a facility named only by a generic name ("City Hospital") or paraphrased.

## Rules (first match wins)

- `provided`: a data file holding provided record ids, sentence ids or facility coordinates
- `restricted`: any data file in external/nabh_accredited, external/nmc_colleges or external/mohfw_trauma_196, and their READMEs when they name a listed facility (table row, numbered list, quote, certificate no.)
- `third_party`: any other data file under external/ (each source's licence: research/DATASETS.md)
- `image`: screenshots or recordings (they show provided facility names)
- `review`: prose or code that mentions a record id or sentence id (usually a quoted example)
- `facility_text`: any other file holding a facility name, phone number or claim sentence from the provided data (dictionary from derived/v1; counts only are printed here)
- `public`: everything else: code, docs without record ids, configuration
