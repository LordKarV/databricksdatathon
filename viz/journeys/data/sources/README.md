# External figures used by the journey stories

mds_snakebite_table3.csv: Table 3 of Suraweera W, Warrell D, Whitaker R, et al. "Trends in snakebite
deaths in India from 2000 to 2019 in a nationally representative mortality study." eLife 2020;9:e54076.
https://elifesciences.org/articles/54076 (read via https://pmc.ncbi.nlm.nih.gov/articles/PMC7340498/ on
2026-11-21). Columns: Million Death Study sampled deaths 2001-14, age-standardised death rates per 100,000
per year for 2001-04, 2005-09, 2010-14, and estimated national deaths 2001-14 in thousands. Transcribed by
hand; the group totals check (higher-burden 557.4 thousand, lower-burden 249.9, all India 807.5).
Headline figures quoted from the same paper: 1.2 million snakebite deaths 2000-2019, average 58,000 a
year; about 70% in eight higher-burden states; about 94% rural; half in June to September.

NHSRC PMNDP counts (1,994 functional public dialysis centres in 751 districts) are read at run time from
data/external/pmndp_counts_and_state_lists/pmndp_state_counts.csv (source https://www.nhsrcindia.org/pmndp-map-table;
see external/pmndp_counts_and_state_lists/README.md for licence: reproduce with attribution).
